# News

## Current rolling publication - 26.08

The Fall 2026 syllabus is maintained as a rolling publication. `VERSION` identifies the current
publication series; there is no formal release or tag boundary.

### Highlights

- Fall 2026 students now have one public syllabus website with direct course pages and complete
  PDF/DOCX downloads generated from the same sources.
- Extra credit now uses category-specific Google Forms, while the movie catalog stays available as
  a separate website-only reference rather than inflating every complete syllabus.
- Help and student services now follow a clearer academic-to-personal order and retain the often
  omitted Schaumburg contacts.
- The student site adds more visible destination cues, including distinct Roosevelt and external
  link marks, plus accessible Roosevelt-themed light and dark presentation.

### Publication model

- One active-term source authority generates the website and complete PDF/DOCX syllabi.
- GitHub Pages regenerates important dates and all complete syllabi before publishing the strict
  MkDocs artifact.
- Local pytest, export E2E, and Playwright lanes provide semantic, document, privacy,
  accessibility, and responsive-layout evidence without defining a formal release.
