## Unreleased - 26.08

The current development update prepares one set of public Fall 2026 course sources for a
student-friendly website and complete PDF and DOCX downloads. The website gives students direct
course routes, task-oriented pages, shared policies, synchronized important dates, and accessible
light/dark themes in Roosevelt University's green palette.

For maintainers, the update establishes one active-term source authority and a fail-fast build
pipeline. GitHub Pages regenerates important dates and all complete syllabi before publishing the
strict MkDocs artifact. Local pytest, export E2E, and Playwright lanes provide deeper semantic,
document, privacy, accessibility, and responsive-layout checks.
