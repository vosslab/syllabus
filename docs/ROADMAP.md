# Documentation roadmap

This roadmap records the bounded work that remains after the Fall 2026 syllabus
publication workflow. It distinguishes ongoing content maintenance from the
next deliberate change in the source-tree design.

## Fall 2026 maintenance

- Keep `site_docs/fall_2026/` as the sole live course and complete-syllabus
  authority.
- Refresh public university statements, dates, contact details, student
  services, and external links when their authoritative sources change.
- Refine course schedules, learning sections, and assessment details only when
  stronger public course information is available.
- Run the complete validation workflow in [USAGE.md](USAGE.md) after a
  material content or pipeline change.

## Spring 2027 rollover

- Design the first historical-term snapshot before adding a second live term.
- Define the snapshot location and the tracked-versus-generated boundary.
- Define how the build pipeline and site navigation select the active term and
  expose an archived term.
- Create the Spring 2027 source tree only after those decisions are recorded
  and implemented.

## Intentionally deferred

- Do not create a template tree, future-term tree, or archive navigation branch
  during Fall 2026.
- Do not move the global website-only movie catalog into a course manifest or a
  complete PDF/DOCX export.
