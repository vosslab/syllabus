# Application dependencies
mkdocs  # static documentation site generator
mkdocs-material  # Material theme for MkDocs
Markdown  # shared MkDocs-compatible parser for print HTML
python-docx  # accessible DOCX post-processing and reference document generation
pypdf  # PDF metadata and bookmark verification
PyYAML  # syllabus manifest parsing
weasyprint  # lightweight tagged PDF rendering from semantic HTML and print CSS
